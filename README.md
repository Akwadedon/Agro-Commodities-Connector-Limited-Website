# Agro-Commodities Connector Limited Website

A responsive B2B agricultural commodities website for Agro-Commodities Connector Limited.

## Corporate credentials
- CAC Registration No.: 9717504
- NEPC Exporters' Registration No.: 004960
- Operating hub: Kano State, Nigeria

## Included
- Responsive corporate homepage
- Official company logo
- B2B commodity marketplace with search/filter
- Buyer RFQ workflow
- Supplier registration entry point
- Incoterms overview
- Export-document checklist
- Resource centre
- Currency preference
- Contact/enquiry workflow
- Mobile navigation
- Accessible, responsive design

## Important
This is a production-ready **front-end foundation**. Authentication, database-backed buyer/supplier accounts, live market prices, payment processing, file uploads, admin approval workflows, email delivery and WhatsApp automation require a backend/service connection and should be added before public transactional use.

## Deployment
This project is suitable for GitHub Pages, Netlify, Vercel or any static hosting provider.

Place the contents of this folder in the repository root so `index.html` is at the top level.
